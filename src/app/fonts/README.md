# Self-hosted editorial fonts

These unmodified Latin WOFF2 webfont subsets are served locally by `next/font/local`.
No browser request to Google Fonts or Adobe is required. System fonts cover missing
glyphs and remain available while fonts load. Only upright fonts are included:
Source Sans 3 is declared at weights 400–700; Source Serif 4 at 400–600.
Variable fonts supply these weights without separate files for each weight.

Both families are licensed under the SIL Open Font License 1.1. Preserve the
complete adjacent copyright/license notices when distributing these files.
The license covers redistribution and web embedding; the font files are not sold
separately. No proprietary photography or fonts are included.
